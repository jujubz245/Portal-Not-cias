# Portal-Not-cias
Pulso News: portal de notícias fictício com 11 páginas, modo claro/escuro, busca, filtros por editoria e favoritos salvos no localStorage. Feito com HTML5, CSS3, JavaScript puro e Bootstrap 5, funciona offline. Projeto acadêmico de Julia Perch e Fernanda Mara – Universidade Positivo.
